# Postcard Scrapbook — FINAL

A 4:3 GitHub Pages recreation inspired by the supplied reference video, with a slower scrapbook feel, clean scene cuts, synchronized audio, and the new six-photo set.

## Files

- `index.html` — scenes and artwork
- `style.css` — layout, drawings, texture, animation
- `script.js` — timing, audio, scene switching, editable lyric placeholders
- `assets/photos/` — six new photos
- `assets/audio/song.mp3` — reference audio

## Edit the lyric text

Open `script.js` and edit only the `lyrics` array near the top. Replace the six placeholder strings with your own permitted text. You can also change their `time` values if you want different lyric moments.

The first lyric is intentionally positioned on the postcard writing line.

## GitHub Pages

Upload the extracted files/folders to the repository root, then enable GitHub Pages from **Settings → Pages → Deploy from a branch** and select your main branch/root folder.

No `.gitignore` is required for the page to work.
